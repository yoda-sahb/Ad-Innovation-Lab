# Idea Radar

> **My personal, independent, company-agnostic ad-tech idea notebook.**

[← Ad Innovation Lab](../README.md) · [Deep dives](README.md) · [Lab Method](../LAB_METHOD.md)

This page is intentionally broader and messier than the deep-dive portfolio.

These are **personal research ideas**, not employer work, client work, company roadmaps, product announcements, or claims that I built or proved any of them. Some are serious product hypotheses. Some are primitives that may collapse into other ideas. Some are deliberately wild because useful research should include things that are probably wrong.

## How to read the scores

### Stage

| Stage | Meaning |
|---|---|
| `TEST NOW` | A bounded experiment can be run mostly on existing rails. |
| `INCUBATE` | The problem looks real; product boundary or distinctiveness still needs work. |
| `RESEARCH` | Mechanism, ownership, economics, or interoperability is unresolved. |
| `MOONSHOT` | Potentially important, but it requires substantial market-structure change. |
| `ANTI-PORTFOLIO` | An idea worth naming mainly because I currently think it should *not* be built. |

### Craziness

`1/5` = mostly an internal decisioning/product change.  
`2/5` = a new reusable product or control layer.  
`3/5` = coordination across multiple systems or companies.  
`4/5` = a new portable market primitive or contract.  
`5/5` = changes what the market clears, owns, settles, or treats as the basic economic unit.

### Probability

The percentage is a **research prior**, not a forecast. It means: *how likely do I currently think some useful product, system, or durable primitive in this direction becomes materially relevant within roughly five years?*

The ranges are intentionally rough. Evidence should move them.

# ANTI-PORTFOLIO

These are ideas I currently think should **not** be built without extraordinary evidence.

| Idea | Why I am skeptical |
|---|---|
| **Universal Open Intelligence Protocol** | Standardizing everything before one bounded decision proves value is backwards. |
| **All-provider invocation on every impression** | Latency, cost, correlated evidence, and complexity explode before contribution is known. |
| **Live self-modifying production agents** | An agent should not rewrite its own permissions, promotion criteria, or production policy from live outcomes. |
| **Automatic intelligence-provider settlement** | Payment before credible causal contribution invites gaming and false precision. |
| **Replace campaign configuration with a universal AI mandate** | Existing objectives, budgets, contracts, and controls encode real business rights; abstraction does not make them disappear. |
| **New exchange because AI exists** | Better intelligence is not evidence that the transaction rail is the bottleneck. |

## Promotion rule

An idea gets a dedicated deep-dive page only when it has at least:

`persistent problem → explicit system boundary → plausible mechanism → bounded proof → kill condition`

Until then, it can stay here as a wild idea.

**Wild is allowed. Confusing an idea with evidence is not.**
